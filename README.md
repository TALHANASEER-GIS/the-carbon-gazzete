# CO2 Emissions Explorer

This is a simple interactive map project created by **Talha Naseer** for my Advance Cartography course at Paris Lodron Universität Salzburg (2026).

## What is this project?
I built this interactive map to show how CO2 emissions per person have changed around the world. It is designed to look like a modern newspaper story.

## How it works
The map lets you:
* **See emission levels**: Watch how much carbon different countries produce per person.
* **Compare with the Paris Agreement**: Switch modes to see if countries have increased or decreased their emissions since the 2015 Paris Accord.
* **Travel through time**: Use the slider to see data from 1960 all the way to 2022.
* **Check specific countries**: Click on any country to see a small chart of its history.

## My code approach
I kept the code as simple as possible to make sure it works well and is easy to read:
* **HTML/CSS**: Used to build the layout and make it look clean and dark.
* **JavaScript**: Used to handle the map logic, the slider, and the charts.
* **Leaflet**: A simple tool that helps display the map.
* **Data**: The information comes from *Our World in Data*.
